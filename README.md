## 🚀 Sobre el Proyecto

**CapyABA** es una plataforma LMS moderna desarrollada para ofrecer experiencias educativas virtuales fluidas y estructuradas. Cuenta con una arquitectura robusta que separa los entornos de administración y estudiantes, integrando validación estricta de seguridad a nivel de base de datos e inteligencia artificial para la certificación automatizada de usuarios.

## ✨ Características Principales

* 👨‍🏫 **Panel de Administración Avanzado:** Herramientas completas para el CRUD de cursos, creación de contenidos interactivos, exámenes dinámicos, tareas digitales y seguimiento analítico de rendimiento por alumno.
* 🎓 **Experiencia de Estudiante (Portal LMS):** Interfaz limpia e intuitiva para el consumo de contenido multimedia, desarrollo de evaluaciones, seguimiento de progreso en tiempo real y descarga de credenciales.
* 🔒 **Control de Acceso Seguro (RLS):** Restricciones estrictas integradas directamente en la base de datos para asegurar que los estudiantes solo visualicen los contenidos e inscripciones explícitamente autorizados.
* 🏆 **Certificación Automatizada con IA:** Generación dinámica de certificados en formato PDF mediante la integración de modelos de lenguaje avanzados (**Groq API** con *Llama 3*).
* 🔐 **Autenticación Moderna:** Soporte para inicio de sesión mediante credenciales tradicionales y Google OAuth.

## 🛠️ Stack Tecnológico

* **Frontend:** Next.js (App Router), React, TypeScript.
* **Estilos:** Tailwind CSS con diseño de paleta personalizada e identidad visual de marca.
* **Backend & Base de Datos:** Supabase (PostgreSQL, Row Level Security, Auth y Storage).
* **Inteligencia Artificial & Utilidades:** Groq API, librerías especializadas para la generación de documentos PDF.
* **Despliegue:** Vercel.
